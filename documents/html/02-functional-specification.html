    Functional specification

    What AccessSutra AI does, command by command, with the exact behavior of findings and manual checks.

    Capabilities#

    IDCapabilityBehaviorCommand
    F1Static scanParse one local HTML file (max 2 MiB), apply 18 rules, emit findings with id, rule, severity, kind, candidate WCAG refs, line, selector, reproduce and remediation textscan
    F2CI gateExit 3 when a finding at or above a severity existsscan --fail-on
    F3Manual plan10 human checks (keyboard, trap, focus visibility, activation, labels, errors, screen reader, zoom/reflow, contrast, cognitive), all not-runmanual
    F4ObservationsReviewer, environment and note required for any tested status; credential-like text rejected; max 500 charsmanual --observations
    F5Evidence reportJSON, Markdown, HTML with summary, findings, manual table, browser status, not-covered list, limitations, sealreport
    F6Browser observationChromium via Playwright: Tab sampling and axe-core violations on file or loopback URLsbrowser
    F7Assurance audit21 checks, gold-corpus accuracy, fuzzing; sealed JSON, Markdown, HTMLaudit
    F8Seal verificationRecompute SHA-256 over canonical JSONverify
    F9LedgerAppend and verify a hash-chained JSONL logaudit append, audit verify
    F10Report APIRead-only, loopback, bearer tokenserve
    F11IDE installCopy instructions into <target>/accesssutra; dry-run supportedinstall-ide
    F12DemoScan the bundled broken signup fixture and write a full reportdemo

    Manual check lifecycle#

    Finding semantics#

    • detected: static evidence in the source (for example an image with no alt attribute).
    • review: a pattern that needs a human (for example a clickable div).
    • Severity is a rule-level heuristic. The report says so. Real impact depends on the task and the person.

    Non-functional requirements#

    Offline by default; deterministic output for the same input; no telemetry; Node.js 22 or newer on Windows, macOS and Linux; zero runtime dependencies; hostile input must never crash the scanner beyond documented limit errors.

    Out of scope#

    Certification, legal conclusions, scanning external sites, submitting forms, screen reader automation, scoring pages.
