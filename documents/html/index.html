    What it does

    A scanner is the start, not the finish

    Automated tools see only part of accessibility. AccessSutra keeps the tool-checkable part and the human-only part in one honest report.

    Static scan, 18 rules

    Names, labels, alt text, language, titles, ARIA references, focus and zoom blockers. Every finding has file, line, selector and a fix.

    Human test plans

    Ten structured checks for keyboard, focus, screen reader, zoom, contrast and cognition. Only a named reviewer can mark one done.

    Real browser, optional

    Playwright and axe-core on file and loopback pages. Tab sampling and rule results join the same report.

    Reports people read

    Sealed JSON, Markdown and HTML with summary cards, finding cards, and a plain list of what was never tested.

    Safe by design

    Offline. No form submission. No external origins. Values and placeholders never copied into output.

    Proof of itself

    One command writes a sealed assurance report: checks, accuracy on a labelled corpus, fuzzing, with limits stated.

    How it works

    From a file to evidence you can send

    Every stage is deterministic. The report states what was never tested.

    1. 1

      Scan

      Point it at a page.

      accesssutra scan --input page.html --out scan.json
    2. 2

      Test

      People run the manual plan and record observations.

      accesssutra manual --task task.json --out manual.json
    3. 3

      Report

      One sealed report, three formats.

      accesssutra report --scan scan.json --manual manual.json --out report

    FAQ

    Quick answers

    Does it make my site WCAG compliant?

    No. It finds some candidates and organises the human testing that proves the rest.

    Does it need an API key or internet?

    No. The scan is fully offline and uses only Node.js built-ins.

    Can it browse or submit forms on my live site?

    No. The optional browser adapter only opens file: and loopback URLs and never submits forms.

    Is the 100% benchmark real?

    It is real and small: 56 cases labelled by the author. It guards against regressions; it is not a claim about other sites.

    Can an AI agent mark a check as passed?

    No. A named reviewer, environment and note are required, and the report says so.

    Can I use it commercially?

    Yes, under Apache-2.0.
