# Glossary

> Terms used across the documentation.

| Term | Meaning |
|---|---|
| a11y | Numeronym for accessibility |
| Accessible name | The text assistive technology announces for a control |
| ARIA | Accessible Rich Internet Applications attributes |
| axe-core | Open-source accessibility rules engine by Deque, used by the optional adapter |
| Candidate finding | A lead that needs confirmation, not a verdict |
| Detected / review | Static evidence found / needs a human to judge |
| Gold corpus | Hand-labelled HTML cases used to measure rule accuracy |
| Seal | SHA-256 of canonical JSON of a report; detects edits |
| Hash chain | Ledger where each event includes the hash of the previous one |
| Loopback | 127.0.0.1 or ::1, reachable only from the same machine |
| Manual check | A human-performed test recorded with reviewer, environment and note |
| Assurance report | Automated self-check report of the tool (not a third-party audit) |
| WCAG | Web Content Accessibility Guidelines, a W3C standard; criteria are cited by number |
