# UX/UI Design System (M3 design specification, not implemented)

**Positioning:** premium, trustworthy, accessible evidence workbench. Core journeys: select task → inspect affected UI state → compare automated findings and manual observations → reproduce barrier → assign fix → retest → independent review.

**Information architecture:** task dashboard, evidence explorer, keyboard focus timeline, form-error state, AT session notes, remediation backlog, regression comparison, human review queue, export center, admin and audit.

**Visual direction:** neutral ink/slate foundation, restrained cyan/teal accents, strong focus rings, semantic typography, ample spacing, evidence provenance adjacent to status, responsive layout from 320px, dark/light themes with measured contrast. Never rely on color alone; avoid green "WCAG compliant" badges.

**Accessibility target:** WCAG 2.2 AA design and test plan, not a claim of achievement. Test with keyboard, zoom, screen reader, motion reduction, touch and cognitive review. Include skip links, accessible charts/tables, semantic landmarks, consistent error messaging and readable exports.
