# Roadmap

- **M0 — Verified offline starter:** limited static scan, manual plan, evidence reports, local API, CLI, agent/skill/workflow/rule contracts, tests. Mark complete only after clean-extraction verification.
- **M1 — Real browser evidence:** install and test Playwright/axe in CI; robust DOM/ARIA analysis, focus trace, safe task scripts, browser/OS versioning, comparison and provenance. **Planned**.
- **M2 — Human-first task lab:** reviewer UI, AT templates, user participation consent, redaction, screenshots opt-in, evidence retention, issue lifecycle. **Planned**.
- **M3 — Accessible web dashboard:** responsive task board, evidence explorer, report compare, prioritization, accessible charts, keyboard and screen reader UX. **Planned**.
- **M4 — Enterprise self-hosted service:** PostgreSQL, OIDC/SSO, RBAC/ABAC, tenant isolation, audit signatures, encryption, backups, policy packs, rate limits, queue. **Planned**.
- **M5 — Ecosystem:** read-only MCP tools, CI/PR adapters, GitHub/GitLab/Azure, Pa11y/Lighthouse optional, WCAG mapping packs and host-specific compatibility tests. **Planned**.

No certification, legal conformance decision or replacement for real user research at any milestone.
